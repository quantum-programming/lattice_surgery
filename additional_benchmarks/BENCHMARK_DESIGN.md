# CNOT+T Microbenchmark Design

This is a small, reproducible pilot corpus for co-author review. It probes
compiler behavior rather than representing an application workload.

## Why these circuits

Herzog et al. study how input-circuit parallelism affects lattice-surgery
routing. Section VII-B defines maximally parallel CNOT circuits, where each
layer uses all qubits in disjoint pairs, and minimally parallel circuits, where
successive layers deliberately reuse a qubit. Section VII-C adds random CNOT+T
circuits with

\[
r=\frac{\#\mathrm{CNOT}}{\#\mathrm{CNOT}+\#T}.
\]

We use the corresponding generators from the pinned MQT QECC implementation:

- [`mqt_max_parallel`](figures/mqt_max_parallel.png): 24 CNOTs arranged in
  maximally parallel layers. This isolates scheduling when dependencies permit
  the greatest concurrency.
- [`mqt_min_parallel`](figures/mqt_min_parallel.png): 24 CNOTs with
  `layer_size=2` and deliberate qubit reuse between successive layers. This
  gives limited, but nonzero, input parallelism.
- [`mqt_random_cnot_t`](figures/mqt_random_cnot_t.png): 24 operations sampled
  with `r=0.5`, producing 12 CNOT and 12 T gates. This exercises both data-data
  routing and access to magic-state factories.

The first two are CNOT-only controls; the third exercises the full CNOT+T gate
set. All use six qubits and seed 45. Six qubits keep exact unitary validation
cheap, while 24 operations satisfy the reviewer's request for a few dozen
gates. These sizes are downscaled from the paper and are not claimed to match
its large-instance statistics.

## Exact generation

The canonical JSON is generated by `scripts/generate_microbenchmarks.py` from
MQT QECC commit `f3c26db10727174af2d2d7c02d1fbee70162a1c0` using:

```python
generate_max_parallel_circuit(q=6, min_depth=24, seed=45)
generate_min_parallel_circuit(q=6, min_depth=24, layer_size=2, seed=45)
generate_random_circuit(q=6, min_depth=24, tgate=True, ratio=0.5, seed=45)
```

Run the complete generation pipeline from this directory with:

```powershell
uv run scripts/generate_microbenchmarks.py
uv run scripts/prepare_microbenchmarks.py
```

The second command constructs Qiskit circuits from the generated JSON, exports
OpenQASM 2, imports it again, checks the exact gate sequence, checks unitary
equivalence up to global phase, and renders the PNG diagrams with Qiskit's
Matplotlib drawer. Tests also compare the checked-in JSON with fresh output from
the pinned MQT generators.

This validates generation and format conversion. It does not yet validate the
lattice-surgery output of any compiler.

## Reference

Beyond the Surface Code,” especially Sections VII-B and VII-C,
arXiv:2504.10591 (2025), <https://arxiv.org/abs/2504.10591>.
